# Security Policy

## Reporting a vulnerability

Please do **not** report suspected security vulnerabilities in a public issue. Use this repository's GitHub **Private vulnerability reporting** feature instead: open the repository's Security tab, choose **Report a vulnerability**, and include a clear description, affected version or commit, reproduction steps, and impact.

If private vulnerability reporting is not enabled or unavailable, do not disclose exploit details publicly. A repository maintainer must enable the feature or provide a verified private reporting channel before a report can be submitted privately.

## Scope and handling

Reports involving authentication material, user data, network input handling, dependencies, or the deployed API are welcome. Do not access data that you do not own or have permission to test. No response-time, remediation-time, or safe-harbor commitment is made by this document.
